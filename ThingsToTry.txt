## mkCDPStatefulRelative — Current Mechanism (ac2822CDPNextLinePointerChasing)

### Data Structures

| Structure | Type | Keyed by | Stores |
|---|---|---|---|
| Training Table | 4-way set-assoc BRAM | hash(vaddr[38:0]) | {storedVaddr, pcHash, relOffset} |
| PC Table | Flat BRAM | hash(pcHash) | {pcHash, Vector#(15, Bit#(3))} — confidence per relOffset -7..+7 |

### On Demand Load Miss Fill (reportIncomingCacheLine)

Slot 0 — Training trigger: reconstruct virtual miss address {vpn, pageOffset(paddr)}, look up in training table.
- Hit: the miss address was previously seen as a pointer by ttRdResp.pcHash at ttRdResp.lineOffset -> saturating-increment that confidence counter in the PC table. If stored pcHash doesn't match incoming pcHash (collision) -> reset confidence vector to zero before writing new entry.
- Miss: nothing.

Slots 1-8 — Candidate scan: scan all 8 line words; any whose upper matchBits VPN bits match the miss address VPN is a candidate pointer.
- TT miss -> write new entry {candVaddr, currentPcHash, relOffset}.
- TT hit, same pcHash -> no write.
- TT hit, different pcHash -> overwrite with new pcHash/relOffset to keep entry current.

PrefetchIssue: one PC table lookup for the current pcHash — feeds the prefetch issue pipeline.

### On Demand Load Hit (reportAccess)

- Enqueues a PrefetchIssue PC table lookup (same pipeline as miss fill).
- Also enqueues a training trigger (slot 0, mutually exclusive with miss-time trigger) — covers warm working sets where fills never occur.

### Prefetch Issue Pipeline (PrefetchIssue PC table response)

Iterate all 15 confidence slots high-to-low (lowest relOffset wins on tie). Find the single best slot where conf >= confidenceThreshold.

absTarget = hitOffset + bestRelOffset

If absTarget in 0-7 (in-bounds): read line[absTarget], validate upper matchBits of its VPN, enqueue to TLB -> physical address -> nextCandidateBuffer -> prefetch issued. Tagged isNeighbourLine=False.

If absTarget out of bounds (<0 or >7): the pointer lives in the neighbouring cache line. We know the exact word offset within that neighbour:
- wordInNeigh = absTarget + 8  (prev case, absTarget in -7..-1)
- wordInNeigh = absTarget - 8  (next case)
Reconstruct curLineVbase = {vpn, lineInPage, 0}, step +-64 bytes to get neighLineVaddr, then compute the exact word vaddr: neighWordVaddr = neighLineVaddr + (wordInNeigh * 8).
Enqueue neighWordVaddr to TLB -> prefetch that cache line. Tagged isNeighbourLine=True.

### Neighbour-Line Pointer Chasing (wasNeighbourPrefetch path in reportIncomingCacheLine)

When a neighbour-line prefetch returns (hit or miss), reportIncomingCacheLine is called with wasNeighbourPrefetch=True. Since req.addr carries the word-level paddr (set from prefetch.addr in L1Bank), getLineDataOffset(req.addr) recovers the exact word index within the now-resident line. That word is read, its upper matchBits VPN bits are checked against req.vpn, and if it passes it is enqueued directly to tlbReqFIFO as a normal candidate (isNeighbourLine=False), feeding into the standard TLB -> nextCandidateBuffer -> prefetch issue pipeline. If the VPN check fails the candidate is dropped.

### Confidence Decay

LFSR fires every decayInterval cycles, picks a random PC table index, saturating-decrements all 15 confidence counters by 1. Stale patterns fade over time.

### Module Parameters

| Parameter | Purpose |
|---|---|
| trainingTableSize | Number of sets in training table |
| pcTableSize | Number of entries in PC table |
| decayInterval | Cycles between decay events |
| matchBits | Upper VPN bits used for candidate pointer detection (cross-page reach) |
| confidenceThreshold | Minimum confidence to issue a prefetch |
